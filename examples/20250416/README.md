# 20250416 304 例子

SDO/AIA 304 与 STEREO-A/EUVI 304 的一对测试数据，FoV 来自作者 QLS 会话里保存的窗口。
数据是全日面 FITS 的裁剪，WCS 与观测者头信息保留，只有像幅变小。FoV 用 2025-04-16 保存页里的窗口。

## 时刻与 FoV

| 格 | 仪器 | 时刻 (UT) | 尺度 |
|---|---|---|---|
| (a) | SDO/AIA 304 | 03:59:53.129 | 0.601 角秒/像素 |
| (b) | STEREO-A/EUVI 304 | 04:00:45.010 | 1.588 角秒/像素 |

视角差 32.87 度，时刻差 52 秒，极线灵敏度 55 角秒每 0.1 R_sun。

| 格 | x 范围 | y 范围 |
|---|---|---|
| AIA 304 | −513.4 到 −155.8 | −107.4 到 250.2 |
| EUVI 304 | −1065.7 到 −681.6 | −184.5 到 199.5 |

## 跑法

界面

```bash
./run.sh
```

无窗口复现

```bash
cd ../..
PYTHONPATH=. .venv/bin/python examples/20250416/make_example.py
```

`make_example.py` 取两个点，第一个点选中后做 Outline 识别，结果写到 `output/`。
